# 🏸 배드민턴 복식 대진표 생성기 (생성자:heesu)

참가자 명단만 넣으면 **복식 대진표를 자동으로 짜 주는** 파이썬 프로그램이에요.
게임 수, 휴식, 성별, 실력(급수·나이)의 균형을 한 번에 맞춰요.

![대진표 화면](docs/screenshot_schedule.png)

## ✨ 주요 기능

- **게임 수 균등**: 모든 사람의 게임 수 차이를 1 이하로 맞춰요.
- **휴식 고르게**: 연속 3게임과 긴 연속 휴식을 최대한 줄여요.
- **성별 모드**: `혼복 위주` / `남복·여복 위주` / `자유` 중에서 골라요.
- **실력 균형**: 급수, 성별, 나이를 반영한 보정 점수로 양 팀 점수를 맞춰요.
- **같은 급수 게임 + 이벤트 게임**: 이벤트 게임(급수 혼합) 비율을 %로 정해요.
- **고정 파트너**: 지정한 두 사람은 항상 같은 팀이에요.
- **중복 최소화**: 같은 파트너나 같은 상대를 반복해서 만나는 걸 줄여요.
- **엑셀 입출력**: 명단을 CSV/엑셀로 불러오고, 대진표와 통계를 엑셀로 저장해요.

## 📖 사용 방법

### 1. 명단 준비
- **파일로 불러오기**: `📂 불러오기` → CSV 또는 엑셀 파일 선택
- **직접 입력**: 화면 아래 `참가자 추가 / 수정`에서 입력하고 `➕ 추가`
- 명단의 사람을 클릭하면 수정할 수 있어요. `💾 명단 저장`으로 다음에 다시 쓸 수 있게 저장해요.
- 처음이라면 `sample_players.csv`를 불러와서 바로 테스트해보세요.

### 2. 대진 설정

| 설정 | 설명 |
|---|---|
| 코트 수 | 인원이 부족하면 쓸 수 있는 코트만 써요 |
| 1인당 게임 수 | 남는 코트를 채우려고 몇 명은 한 게임 더 할 수 있어요 |
| 성별 모드 | `혼복 위주` / `남복·여복 위주` / `자유` |
| 이벤트 게임 비율(%) | 급수를 섞는 게임의 비율 (0이면 전부 같은 급수 게임) |
| 탐색 시간(초) | 길수록 결과가 좋아져요. 보통 5~10초면 충분해요 |
| 성별 구성이 다른 대결 허용 | 켜면 "남남 vs 남녀"처럼 성별 구성이 다른 팀끼리도 점수만 맞으면 붙여요 |

설정 아래에 **예상 라운드 수와 게임 수**가 미리 보여요.

### 3. 생성하고 확인하기
`🏸 대진표 생성`을 누르면 탐색 시간 동안 가장 좋은 대진을 찾아요.

| 탭 | 내용 |
|---|---|
| 대진표 | 라운드별 휴식 명단, 코트별 팀·점수, 게임 종류. 이벤트 게임은 주황색이에요 |
| 인원별 통계 | 게임 수, 경기 패턴(● 경기 / ○ 휴식), 연속 경기, 게임 종류별 횟수, 중복 횟수 |
| 요약 | 전체 게임 수, 양 팀 점수 차 평균과 최대, 게임 종류별 개수 |


### 4. 엑셀로 저장
`📊 엑셀로 저장`을 누르면 시트 4개가 들어간 엑셀 파일이 만들어져요: `대진표`, `인원별 통계`, `요약`, `참가자 명단`.
대진표 시트는 가로 방향 인쇄로 설정돼 있어서 바로 출력해 붙일 수 있어요.

## 📋 명단 파일 형식

첫 줄은 머리글, 둘째 줄부터 한 줄에 한 명씩 적어요. `.xlsx`, `.csv` 모두 돼요.

| 이름 | 나이 | 성별 | 급수 | 고정파트너 |
|---|---|---|---|---|
| 김민준 | 28 | 남 | A | 임서연 |
| 임서연 | 29 | 여 | A | |
| 박도윤 | 45 | 남 | B | |
| 황예린 | 36 | 여 | 초심 | |

| 칸 | 필수 | 값 | 이렇게 써도 돼요 |
|---|---|---|---|
| 이름 | ✅ | 겹치지 않게 | |
| 나이 | ✅ | 숫자 | |
| 성별 | ✅ | `남` / `여` | `남자`, `여자`, `M`, `F` |
| 급수 | ✅ | `A` / `B` / `C` / `D` / `초심` | `b급`, `초보` |
| 고정파트너 | | 파트너 이름 (없으면 비움) | 한쪽에만 적어도 돼요 |

- 머리글은 `성명`, `파트너`처럼 조금 달라도 알아들어요. 열 순서도 상관없어요.
- 한국어 엑셀에서 저장한 CSV(CP949)도 읽을 수 있어요.
- 잘못된 값이 있으면 몇 번째 줄인지 알려줘요.

## 🧮 보정 점수

팀 균형은 아래 **보정 점수의 합**으로 맞춰요.

```
기본 점수:   A=6, B=4, C=3, D=2, 초심=1
남자 보정:   +2
나이 보정:   39세 이하 +1 / 40~59세 0 / 60세 이상 -1
※ 초심은 보정 없이 항상 1점
```

예를 들어 같은 나이대라면 **여자 A급 = 남자 B급**이 돼요.

## ⚖️ 우선순위

조건끼리 부딪히면 위에 있는 걸 먼저 지켜요.

| 순위 | 항목 | 처리 |
|---|---|---|
| 0 | 고정 파트너 | 반드시 지킴 |
| 1 | 게임 수 균등 (차이 1 이하) | 반드시 지킴 |
| 2 | 휴식 고르게 + 연속 3게임 최소화 | 벌점 |
| 3 | 성별 모드 | 벌점 |
| 4 | 양 팀 점수 균형 | 벌점 |
| 5 | 같은 급수 구성 / 이벤트 게임 고르게 나누기 | 벌점 |
| 6 | 파트너·상대 중복 최소화 | 벌점 |

벌점 크기는 `scheduler.py` 맨 위의 `W_...` 상수로 조절할 수 있어요.

## 🔧 동작 원리

1. **게임 수 정하기**: 라운드 수 = ⌈인원 × 게임 수 ÷ (코트 × 4)⌉
2. **1단계 – 휴식 패턴**: 누가 어느 라운드에 쉴지 [담금질 기법](https://ko.wikipedia.org/wiki/담금질_기법)으로 정해요. 쉬는 간격과 라운드별 남녀 인원을 같이 맞춰요.
3. **2단계 – 조 편성**: 사람·팀을 바꾸거나 두 게임을 통째로 다시 짜면서 벌점 합을 줄여요.

## 💡 알아두면 좋은 점

- 쉬는 사람이 적은 구성(예: 16명·3코트 → 12명 뛰고 4명 쉼)에서는 연속 3게임을 피할 수 없는 사람이 생겨요.
- 휴식(우선순위 2)이 성별 모드(우선순위 3)보다 우선이라, 휴식을 지키려다 혼성 대결이 조금 생길 수 있어요.
- 아주 강한 고정 파트너는 점수가 맞는 상대가 없어서 점수 차가 날 수 있어요.
